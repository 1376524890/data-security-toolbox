# Data Security Toolbox V2.1 Component Integration Upgrade Report

生成时间：2026-09-02
范围：Data Security Toolbox V2.1 组件集成升级

## 完成项

### 1. Integration Adapter Layer

新增 `backend/app/integrations/`，所有第三方组件通过统一接口接入：

```text
第三方工具输入
      ↓
IntegrationAdapter
      ↓
DetectionResult
      ↓
RiskEngine
      ↓
DetectionFinding
```

实现内容：

- `base.py`：`IntegrationAdapter`、`AdapterResult`、Finding 构造与严重度映射
- `registry.py`：适配器注册与元数据查询
- `engine.py`：`IntegrationAdapterEngine`，将第三方适配器桥接到现有 `DetectionEngine` 流水线
- `runner.py`：`Adapter -> DetectionResult -> RiskEngine` 标准执行入口
- `offline.py`：规则、IOC、CVE、模型离线导入/导出

### 2. Zeek 集成

目录：`backend/app/integrations/zeek/`

支持：

- PCAP 输入并通过 Zeek 执行
- JSON 与 TAB 分隔日志解析
- `conn`、`dns`、`http`、`ssl`、`files`、`weird`
- DNS 高熵/长域名、TLS 证书异常、HTTP 扫描 UA/动态脚本上传、可疑文件、Zeek weird、大流量会话

新增规则示例：

### 8. 事件关联：incident_engine

目录：`backend/app/incident_engine/`

逻辑：

```text
多个 Finding
      ↓
时间窗口 / 资产 / IOC / 攻击链
      ↓
Incident
```

支持：

- 同资产多事件聚合
- IOC 命中聚合
- 攻击链阶段：recon -> exploit -> credential -> c2 -> exfil -> impact
- Incident 持久化到 `incidents` 表
- API：`GET /incidents`、`GET /incidents/{id}`、`POST /incidents/correlate`

### 9. 离线能力

实现：

- `backend/app/integrations/offline_data/` 包含规则、IOC、CVE、模型示例
- `scripts/offline_bundle.py` 生成 `dist-offline/data`
- 支持 JSON、JSONL、YAML、CSV、TSV、Suricata `.rules`
- API：`POST /integrations/offline/import`

### 数据流

```text
PCAP/JSON/XML/主机数据
      ↓
Zeek / Suricata / Presidio / MISP / osquery / Wazuh / OpenSCAP Adapter
      ↓
DetectionResult
      ↓
RiskEngine
      ↓
DetectionFinding
      ↓
IncidentEngine
      ↓
Incident
```

第三方适配器同时作为 `IntegrationAdapterEngine` 注册到现有 `EngineRegistry`，因此可参与统一 `DetectionPipeline`。

## 剩余问题

1. Zeek、Suricata 实际执行依赖部署环境已安装对应二进制，或通过集成 Docker 服务挂载执行目录；当前测试使用合成日志，不依赖本机二进制。
2. ET Open Rules 已实现导入器和离线样本；正式规则包需放置到 `backend/app/integrations/offline_data/rules/` 或运行在线导入脚本。
3. Presidio 生产环境建议安装离线 spaCy 中文/多语模型，否则会回退到内置正则 Recognizer。
4. MISP、Wazuh、osquery 的 Docker 服务为重型组件，未在本轮实际拉取启动；部署时需要配置 `MISP_URL`、`MISP_API_KEY`、`WAZUH_URL`、`OSQUERY_SOCKET`。
5. `incident_engine` 当前按规则关键词和资产/IOC 做聚合，未接入复杂 ML 关联模型；后续可按 ATT&CK 图谱和真实告警时间窗调优。
6. 报告模板已支持 Incident 区块，前端管理端尚未新增独立 Incident 页面，当前可通过 API 获取。
