## 升级与回退边界

1. 本版没有新迁移：升级只需替换镜像并重启容器，数据库结构无需变更；升级前仍建议备份数据库与文件存储。
2. 回退代码不等于回退数据。本版没有写入结构或历史数据，回退到 v2.12.0 快照不需要数据侧操作。
3. 接口集合与表结构未变，探针与分发包未变，已入网的 3.5.0 探针无需升级。
4. 发现回归时停止推广，保留现场与审计，用新修复提交或经验证的旧镜像回退处理，不重写历史标签。
